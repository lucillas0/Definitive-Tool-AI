# Shark Tank — knowledge siempre-activo (Freebuff/Codebuff)

Copia este archivo a tu proyecto como `knowledge.md` o fusiona su contenido
en tu `AGENTS.md`. Las skills son on-demand; esto es lo que aplica SIEMPRE.

## Regla

- Brief vago -> momento 0: thinking-orbs, agent-reach, mirofish. Define éxito antes de dibujar.
- Diseñar/prototipar/animar -> momento 1: taste, ui-ux-pro-max, motion-design, hallmark, hairline.
- Auditar/revisar/QA/comparar -> momento 2: shark, impeccable, arena, playwright. Entrega fallos + fixes.
- Crear componentes/páginas -> momento 3: shadcn, ecc, xtool, playwright. Reutiliza el sistema.
- Sin skill instalada -> momento 4: `npx skills find "<tema del momento>"`, verifica installs/fuente.
- Presentar/elegir -> momento 5: shark, arena, hallmark con veredicto.
- Sistematizar/tokens -> momento 6: shadcn, ecc, ui-ux-pro-max, xtool.
- UI vieja/migrar -> momento 7: impeccable, arena, playwright.

Detalle completo: `.agents/skills/shark-design/SKILL.md`. Cierre obligatorio:
momento detectado (0-7), skill usada, skill a instalar.
